# ジュニアエンジニア研修 確認テスト

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。

## ビルド（静的ファイル生成）

```bash
npm run build
```

`dist/` フォルダに静的ファイルが生成される。

## 問題の追加・編集

`src/App.jsx` の先頭にある `COURSES` 配列を編集する。

### 問題の構造

```js
{
  no: 1,              // 問題番号
  type: "選択",       // "選択" または "記述"
  level: "基礎",      // "基礎" または "応用"
  conceptId: "c1-1",  // 紐付ける概念のID
  q: "問題文",
  choices: [          // 選択式のみ。記述式は不要
    "A. ...",
    "B. ...",
  ],
  answer: "A",        // 選択式: 正解の記号。記述式: 解答例テキスト
  point: "解説文",    // 選択式のみ（answerとは別に解説を書く場合）
}
```
